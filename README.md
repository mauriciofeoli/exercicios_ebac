# Exercícios EBAC

Repositório com atividades práticas do curso de Qualidade de Software da EBAC.

## Objetivo

- revisar conceitos de qualidade de software;
- praticar testes e análise de requisitos;
- trabalhar com histórias de usuário e documentação ágil;
- consolidar estudos sobre desenvolvimento e validação de software.

## Conteúdo

- exercícios de Gherkin;
- materiais de apoio em documentos `.docx`;
- atividades relacionadas a qualidade, métricas e processos ágeis.
